How to read the dashboard correctly

Interaction: az országok közös megjelenése és témakapcsolata.
Interest: egy téma relatív súlya az adott országhoz kapcsolódó eseményekben.
Voting: külön adatbázis alapján mért együttszavazási kapcsolat.
Coalition: csak akkor nevezzük annak, ha a kapcsolatot érdekalapú, álláspont- és szavazási adatok is alátámasztják.
